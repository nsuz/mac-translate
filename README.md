# Translate

On-device translation for macOS. Select text in any app, press a shortcut, and read the translation in a popover. Nothing leaves your Mac.

Built with PLaMo. Translate runs PLaMo 3 Translate locally through llama.cpp.

## Status

Under development and not yet usable.
